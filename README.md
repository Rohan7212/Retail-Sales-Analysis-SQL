# Retail Sales Analysis using MySQL

## Overview
This project analyzes a retail sales dataset containing 9,694 records using MySQL. The analysis focuses on sales performance, customer behavior, product profitability, and regional trends.

## Dataset
- Sample Superstore Dataset
- Records: 9,694

## SQL Concepts Used
- Aggregate Functions
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- Views
- Stored Procedures
- Window Functions
- Date Functions

## Business Questions Solved
- Total Sales
- Total Profit
- Top Selling Products
- Top Customers
- Sales by Region
- Monthly Sales Trend
- Product Profitability
- Customer Ranking

## Tech Stack
- MySQL
